# Menu settings to look for, one per line, taken from the monitor's own menus (so the
# names match what you see there). "Name | text": the text is something to set up first;
# walk.sh waits for it BEFORE reading the baseline, so that it is not mistaken for the
# change. When every line has been walked, add the entries of your other menus here.
PBP Input | In the monitor's menu set PBP mode to PBP (or run ./monitor pbp on) and wait until both pictures show. Then you will change PBP Input (the right window's source), for example from USB-C to HDMI-1.
SmartContrast
SmartResponse | Check that SmartResponse is Off (it is the current value) and do not change it yet. In step 3 you will change it from Off to Fast.
SmartResponse: Fast to Faster | Set SmartResponse to Fast now (it is Off). Then in step 3 change it from Fast to Faster.
SmartResponse: Faster to Fastest | Set SmartResponse to Faster now. Then in step 3 change it from Faster to Fastest.
Picture Format | Picture Format is Wide Screen now: do not change it yet. In step 3 change it to the NEXT option the menu offers, and write down its name.
Picture Format: next option | Set Picture Format to the second option now. In step 3 change it to the third option (answer x if it only has two) and write down its name.
Picture Format: 1:1 | Set Picture Format to 16:9 now (it is Wide Screen). Then in step 3 change it to 1:1. (Movie 1 and Movie 2 are greyed out in the menu, so they cannot be walked.)
SmartImage: Off to EasyRead | SmartImage is Off now (it is the current mode): do not change it yet. In step 3 change it from Off to EasyRead.
SmartImage: EasyRead to Office | Set SmartImage to EasyRead now. Then in step 3 change it from EasyRead to Office.
SmartImage: Office to Photo | Set SmartImage to Office now. Then in step 3 change it from Office to Photo.
SmartImage: Photo to Movie | Set SmartImage to Photo now. Then in step 3 change it from Photo to Movie.
SmartImage: Movie to Game | Set SmartImage to Movie now. Then in step 3 change it from Movie to Game.
SmartImage: Game to Economy | Set SmartImage to Game now. Then in step 3 change it from Game to Economy.
SmartImage: Economy to LowBlue Mode | Set SmartImage to Economy now. Then in step 3 change it from Economy to LowBlue Mode.
SmartImage: LowBlue Mode to SmartUniformity | Set SmartImage to LowBlue Mode now. Then in step 3 change it from LowBlue Mode to SmartUniformity.
SmartImage: SmartUniformity to Off | Set SmartImage to SmartUniformity now. Then in step 3 change it from SmartUniformity to Off.
LowBlue Mode: Off to 1 | Check in the monitor's menu (the first item, not the SmartImage button) that LowBlue Mode is Off, and set SmartImage to Off too (use the first button). Do not change LowBlue Mode yet. In step 3 turn it On at level 1.
LowBlue Mode: 1 to 2 | Set LowBlue Mode to level 1 now (in the monitor's menu (the first item, not the SmartImage button)). Then in step 3 change it to level 2.
LowBlue Mode: 2 to 3 | Set LowBlue Mode to level 2 now (in the monitor's menu (the first item, not the SmartImage button)). Then in step 3 change it to level 3.
LowBlue Mode: 3 to 4 | Set LowBlue Mode to level 3 now (in the monitor's menu (the first item, not the SmartImage button)). Then in step 3 change it to level 4.
LowBlue Mode: 4 to Off | Set LowBlue Mode to level 4 now (in the monitor's menu (the first item, not the SmartImage button)). Then in step 3 turn it Off.


HDMI1 EDID Switch: 1 to 2 | In the monitor's menu (HDMI EDID Switch) HDMI1 EDID Switch is on 1 (the 5120x1440 modes are available). Do not change it yet. In step 3 change it to 2. The screen may go black for a moment; 5120x1440 disappears and the maximum becomes 4K. walk.sh reports what the EDID change was.
HDMI1 EDID Switch: 2 to 1 | HDMI1 EDID Switch is on 2 now. In step 3 change it back to 1 (this brings back the 5120x1440 modes).
HDMI1 EDID Switch: 1 to 2 (again) | HDMI1 EDID Switch is on 1 again. In step 3 change it to 2 once more, to check that the EDID change repeats; then change it back to 1 yourself afterwards.
HDMI2 EDID Switch: 1 to 2 | HDMI2 EDID Switch is on 1 (the default). Do not change it yet. In step 3 change it to 2. (Presumably like HDMI1's but for the HDMI 2 port; nothing is connected to HDMI 2 and this laptop is on HDMI 1, so its effect cannot be seen here: the round only shows whether a DDC code moves or HDMI-1's EDID changes.)
HDMI2 EDID Switch: 2 to 1 | HDMI2 EDID Switch is on 2 now. In step 3 change it back to 1.
